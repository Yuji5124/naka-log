# なかログ

**ふたりのお金を、かんたん記録。**

夫婦2人で使う、とにかく入力がかんたんな家計簿です。
「家計簿」というより、**夫婦2人のお金の生活ログ**。

```
カテゴリを押す（🍚 食費）→ 数字を押す（850）→ 完了
```

これだけで記録されます。保存ボタンはありません。押した瞬間に自動で保存されます。

---

## できること（v0.1）

| 画面 | できること |
| --- | --- |
| 今日 | 大きなカテゴリボタンから記録。夫婦2人の記録が1本のタイムラインに並ぶ |
| カレンダー | 1か月の各日の合計。日付をタップすると、その日の記録 |
| 集計 | 今月合計・誰のため（自分／妻／家族）・カテゴリ別・使った人別 |
| 設定 | この端末を使う人、予算、テーマ、バックアップ／復元、CSV書き出し |

- 記録をタップすると、金額・カテゴリ・使った人・誰のため・メモ・日時の修正、削除ができます
- 削除してもしばらく「元に戻す」ボタンが出るので、押し間違えても安心です
- 同じカテゴリを最近入力していれば「いつもの 電車 ¥220」のようなボタンが出て、数字を打たずに記録できます
- ネットがつながらない場所でも起動・記録できます（ホーム画面に追加した場合）

## はじめかた

### 1. GitHub へアップロード

1. GitHub で、このアプリ用のリポジトリ（例：`naka-log`）を開きます
   - まだなければ、右上の「＋」→「New repository」で作ります。**Public（公開）** を選んでください
2. 「**Add file**」→「**Upload files**」をクリック
3. 上の「ファイル一覧」のファイルを**全部まとめて**ドラッグ＆ドロップ
4. 下の「**Commit changes**」をクリック

> 💡 すでに同じ名前のファイルがある場合は、上書きされます。

### 2. GitHub Pages を ON にする

1. リポジトリの上のメニューから「**Settings**」を開く
2. 左のメニューの「**Pages**」をクリック
3. 「Build and deployment」の「Source」で「**Deploy from a branch**」を選ぶ
4. 「Branch」で「**main**」と「**/(root)**」を選んで「**Save**」
5. 1〜2分待つと、ページ上部に公開URLが表示されます

> 💡 無料プランでは、リポジトリが **Public（公開）** でないと GitHub Pages を使えません。
> 公開されるのはアプリのプログラムだけで、**記録したお金のデータはそれぞれのスマホの中にだけ保存されます**（ネットには送られません）。

### 3. URL へアクセス

公開URLはこのような形です：

```
https://ユーザー名.github.io/リポジトリ名/
```

例：`https://yuji5124.github.io/naka-log/`

初めて開くと「**この端末を使うのは？**」と聞かれるので、

- 自分のスマホなら「👨 自分」
- 妻のスマホなら「👩 妻」

を選びます。以降、その端末で記録すると「使った人」が自動でその人になります（記録のときにワンタップで変更もできます）。

### 4. iPhone のホーム画面へ追加

> ⚠️ **大事**：iPhoneでは、**Safariで開いたなかログ** と **ホーム画面から開いたなかログ** は、記録が**別々に保存**されます。
> 記録を始める前に、先にホーム画面へ追加して、そこから使い始めてください。

1. iPhone の **Safari** で公開URLを開く
2. 画面下の **共有ボタン**（□に↑のマーク）をタップ
   - 見当たらないときは「…」→「共有」
3. 下のほうにある「**ホーム画面に追加**」をタップ
4. 名前が「なかログ」になっていることを確認して「**追加**」
5. 以降は、ホーム画面の「なかログ」アイコンから開きます

**Android（Chrome）の場合**：右上の「︙」→「**ホーム画面に追加**」または「**アプリをインストール**」。

ふたりとも、それぞれのスマホで 3 → 4 を行ってください。

## 使い方

1. 下の大きなボタンからカテゴリを押す（🍚 食費、🚃 交通 など）
2. 数字を押す（`+100` `+500` `+1,000` ボタンも使えます）
3. 「**完了**」を押す

それだけです。必要なときだけ、入力画面の下で次を変えられます。

- **使った人**：お金を払った人（👨 自分 / 👩 妻）
- **誰のため**：誰のための支出か（👨 自分 / 👩 妻 / 👪 家族）
  - 例：妻が子どもの物を買った → 使った人＝妻、誰のため＝家族
  - 食費・日用品・子ども・固定費・その他は最初から「家族」、交通・娯楽・衣服は「使った人」になっています
- **メモ**：なくてもOK

**ちょっとしたコツ**

- 昨日の分を忘れていたら、今日画面の日付の「＜」で昨日にしてから記録します
- カレンダーで日付を選んで「＋ この日に記録する」でもOK
- ⌫ を長押しすると、金額を全部消せます
- 記録をタップ →「🔁 もう一度記録」で、同じ内容を今の時刻で記録できます

## データについて（必ずお読みください）

- 記録は **そのスマホの中だけ** に保存されます（v0.1では夫婦のスマホ同士は同期しません）
- 次のようなときは記録が消えることがあります
  - スマホの機種変更・故障・初期化
  - ホーム画面の「なかログ」アイコンを削除したとき
  - iPhoneの「設定 → Safari → 履歴とWebサイトデータを消去」をしたとき
- そのため、**月に1回くらい「設定 → JSONでバックアップ」** をしておいてください
  - iPhoneでは共有画面が出るので「ファイルに保存」を選ぶと、iCloud Drive などに保存できます
  - しばらくバックアップしていないと、今日画面にお知らせが出ます
- 復元は「設定 → JSONから復元」でバックアップファイルを選ぶだけです
  - **今ある記録は消えません**（同じ記録はより新しい方が残ります）
  - 機種変更のときも、古いスマホでバックアップ → 新しいスマホで復元、でOKです
- 「CSVで書き出す」で、Excel や Numbers で開ける表にできます
- 保存に失敗したときは、画面の上に赤いお知らせが出ます

## アプリを更新するとき

1. 新しいファイルを、はじめと同じ「Add file → Upload files」で上書きアップロード
2. 1〜2分待つ
3. スマホでなかログを開く（ネットにつながった状態で）

ネットにつながっていれば、自動で新しいファイルを読み込む仕組みになっています。
古い画面のままのときは、なかログを**完全に閉じて**（アプリ切り替え画面で上にスワイプ）からもう一度開いてください。

> ⚠️ 表示がおかしくても、「Safariの履歴とWebサイトデータを消去」は**記録も消えてしまう**ので、やる前に必ずバックアップしてください。

## 困ったとき

| こんなとき | こうしてください |
| --- | --- |
| URLを開くと 404 になる | Pages を ON にしてから数分待つ。`index.html` が一番上の階層にあるか確認 |
| ホーム画面のアプリに Safari で記録した分がない | Safari側で「JSONでバックアップ」→ ホーム画面のアプリで「JSONから復元」 |
| 「この環境では記録を保存できません」と出る | プライベートブラウズを解除して開き直す |
| 自分／妻を間違えて選んだ | 設定 →「この端末を使う人」で変更 |
| 妻のスマホで「自分」という表示がわかりにくい | 設定 →「呼び名とカテゴリ名の変更」で「夫」や名前に変えられます |

## 開発メモ（将来の夫婦同期に向けて）

### データの形

```js
{
  id: "uuid",
  amount: 850,                 // 円（整数）
  category: "food",            // food / daily / transport / kids / fun / fixed / clothes / other
  payer: "self",               // 使った人：self / wife
  for: "family",               // 誰のため：self / wife / family
  datetime: "2026-10-03T03:15:00.000Z", // いつの支出か（ISO 8601）
  memo: "",
  createdAt: "...",
  updatedAt: "...",            // 同期時は新しい方を採用する想定
  deletedAt: null              // 削除は「削除済みの印」を付ける（論理削除）。同期で削除を伝えるため
}
```

「入力した人（payer）」と「誰のためのお金か（for）」を分けて持っています。
カテゴリ名・呼び名は表示用の設定なので、変えても過去の記録は壊れません。

### 保存処理の分離（StorageAdapter）

`app.js` の中で、保存処理は画面から切り離されています。

```
画面（今日・カレンダー・集計・設定）
   ↓ 使うのはこれだけ
Repository（add / update / remove / restore / merge）
   ↓
StorageAdapter（ここを差し替える）
   ├ IndexedDBAdapter    … 通常はこれ
   ├ LocalStorageAdapter … IndexedDBが使えないときの予備
   └ （将来）FirebaseAdapter / SupabaseAdapter
```

どの Adapter も次のメソッドを持ちます。

```
init()
getTransactions()
saveTransaction(tx)
updateTransaction(id, patch)
deleteTransaction(id)     // 論理削除
bulkPut(list)
clearAll()
getSetting(key) / setSetting(key, value)
subscribe(callback)       // 外部で変更があったら呼ばれる（リアルタイム同期の受け口）
```

クラウド同期を足すときは、同じメソッドを持つ Adapter を作って `createAdapter()` で返すものを変えれば、画面側はそのまま動きます。
`subscribe()` は今は「同じ端末の別タブでの変更」を受け取っています。将来はここにもう一方のスマホからの変更を流す想定です。

### オフライン対応（service-worker.js）

- 方針は「**ネット優先 → だめならキャッシュ**」
- GitHub にファイルを上書きするだけで更新が届くので、バージョン番号を書き換える必要はありません
- パスはすべて相対パスなので、`https://ユーザー名.github.io/リポジトリ名/` の下でもそのまま動きます
